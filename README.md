# Python From Scratch

A beginner-friendly Python learning repository containing practical examples, exercises, and small programs designed to help learners understand Python step by step.

The repository starts with Python fundamentals and gradually progresses into data structures, functions, modules, exception handling, file handling, OOP, databases, libraries, networking, multithreading, GUI development, regular expressions, and other useful concepts.

## About This Repository

This repository is built as a practical learning resource rather than a single project.

Each example focuses on a specific concept so that you can:

* Read the code
* Understand the concept
* Run the example
* Modify the code
* Experiment with different inputs
* Practice the concept yourself

Small concepts are intentionally kept separate to make learning and revision easier.

## Getting Started

### 1. Clone the repository

```bash
git clone <repository-url>
cd python_from_scratch
```

### 2. Check your Python version

```bash
python --version
```

Python 3.x is recommended.

### 3. Run an example

Start from the beginning and work through the examples in sequence:

```bash
python S01_InitialisingTheVariable.py
```

Then continue with the following examples.

For GUI, database, networking, or library-based examples, additional configuration or dependencies may be required.

## Installing Common Libraries

Some examples use third-party Python libraries.

```bash
pip install numpy pandas matplotlib scipy
```

Install only the libraries required by the examples you are working with.

## Recommended Learning Approach

The best way to use this repository is not simply to copy and run the programs.

For each topic:

1. Read the example.
2. Run the program.
3. Understand what each part does.
4. Change the values or code.
5. Observe the result.
6. Try writing the example again yourself.
7. Move to the next concept.

You will learn more by experimenting with the examples than by only reading them.
